# Collection Functions

Functions for manipulating lists and maps. These functions are available globally.

## List Functions

### reverse

Return a new list with elements in reverse order.

**Syntax:** `call reverse with list`

**Example:**
```kronos
set original to list 1, 2, 3, 4, 5
set reversed to call reverse with original  # Returns [5, 4, 3, 2, 1]
```

**Note:** Returns a new list; does not modify the original.

### sort

Return a new sorted list.

**Syntax:** `call sort with list`

**Example:**
```kronos
set unsorted to list 3, 1, 4, 1, 5
set sorted to call sort with unsorted  # Returns [1, 1, 3, 4, 5]

set words to list "zebra", "apple", "banana"
set sorted_words to call sort with words  # Returns ["apple", "banana", "zebra"]
```

**Note:** 
- Returns a new list; does not modify the original
- Works with numbers or strings, but all elements must be the same type
- Sorting is done in ascending order

### filter

Return a new list containing only elements where the callback returns a truthy value.

**Syntax:** `call filter with list, callback`

**Example:**
```kronos
set numbers to list 1, 2, 3, 4, 5
set evens to call filter with numbers, function with x: return x mod 2 is equal 0
# evens -> [2, 4]
```

### map

Return a new list where each element is transformed by the callback.

**Syntax:** `call map with list, callback`

**Example:**
```kronos
set numbers to list 1, 2, 3
set doubled to call map with numbers, function with x: return x times 2
# doubled -> [2, 4, 6]
```

## Length

### len

Get the length of a list or map.

**Syntax:** `call len with collection`

**Example:**
```kronos
set numbers to list 1, 2, 3, 4, 5
set length to call len with numbers  # Returns 5
```

## Examples

### Sorting Numbers

```kronos
set scores to list 85, 92, 78, 96, 88
set sorted_scores to call sort with scores

print "Original:"
print scores
print "Sorted:"
print sorted_scores
```

### Reversing a List

```kronos
set items to list "first", "second", "third"
set reversed_items to call reverse with items

for item in reversed_items:
    print item  # Prints: third, second, first
```

### Finding Maximum Value

```kronos
set numbers to list 3, 7, 2, 9, 1, 5

# Sort and get last element
set sorted_nums to call sort with numbers
set length to call len with sorted_nums
set max_val to sorted_nums at (length minus 1)

print max_val  # Prints: 9
```

### Working with Sorted Data

```kronos
set data to list 42, 15, 8, 23, 4, 16
set sorted_data to call sort with data

print "Sorted data:"
for num in sorted_data:
    print num

# Get median (middle value)
set length to call len with sorted_data
set middle_index to length divided by 2
set median to sorted_data at middle_index
print f"Median: {median}"
```

### Combining List Operations

```kronos
set original to list 5, 2, 8, 1, 9, 3

# Sort first
set sorted to call sort with original

# Then reverse to get descending order
set descending to call reverse with sorted

print "Ascending:"
print sorted
print "Descending:"
print descending
```

## Collection Aggregation

These functions are available globally or through the `collections` module.

| Function | Description |
| --- | --- |
| `zip(list1, list2, ...)` | Combine items into tuples, stopping at the shortest list |
| `enumerate(list)` | Return `(index, item)` tuples starting at zero |
| `any(list)` | Return whether at least one item is truthy |
| `all(list)` | Return whether every item is truthy; empty lists return `true` |
| `sum(list)` | Sum a list containing only numbers; empty lists return `0` |

```kronos
import collections
set pairs to call collections.zip with [1, 2], ["a", "b"]
set indexed to call collections.enumerate with [10, 20]
set total to call collections.sum with [1, 2, 3]
```
